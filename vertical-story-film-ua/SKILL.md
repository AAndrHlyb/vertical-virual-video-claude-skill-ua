# Вертикальний сюжетний ролик українською

Відмальовування кодом на canvas, не генерація. Для flat-вектора це точніше за будь-яку video-модель: персонаж не мутує, краї рівні, склейки стають по кадру, правки коштують секунди.

**Мова ролика — українська.** Увесь текст на екрані (субтитри, HUD, плашки, лічильники, титри) і файли озвучення — українською. Перевір, що шрифт має кирилицю з українськими літерами `і ї є ґ`: `fc-list :lang=uk`.

**Про озвучення скажи одразу:** TTS у цьому середовищі зазвичай недоступний (PyPI/npm/HF/GitHub відрізані). Віддавай ролик із вшитими субтитрами + `ozvuchennia.txt`/`.srt`; надішлють доріжку — підкладаєш.

## Порядок роботи

Три дешеві звірки до дорогого кроку. Це головна економія: рендер коштує 3 хвилини, зміна напряму після нього — уся робота наново.

1. **Сюжет** — одна фраза правила світу + таблиця актів. Показати текстом.
2. **Лук** — 3 кадри в повному розмірі: герой крупно, істота, найскладніша вставка. Є референс — клади поруч його кадр. Надіслати картинкою.
3. **Проби і QA** — аркуш поз, аркуш ходи, контакт-аркуші всіх планів, автотести (етап 7). Дивишся сам.

Тільки потім рендер. Якщо користувач сказав «одразу роби» — пропусти 1 і 2, але 3 ніколи.

## Етап 0 — заміри референсу

Не описуй референс словами — виміряй. Це числові цілі для грейду й монтажу.

```bash
ffprobe -v error -show_entries format=duration -show_entries stream=width,height,r_frame_rate -of default=noprint_wrappers=1 ref.mp4
ffprobe -v error -of csv=p=0 -f lavfi "movie=ref.mp4,select=gt(scene\,0.25)" -show_entries frame=best_effort_timestamp_time 2>/dev/null | tr '\n' ' '
ffmpeg -nostdin -i ref.mp4 -filter_complex ebur128 -f null /dev/null 2>&1 | grep -A8 Summary
```

Палітра і тон: кадри `fps=1/3,scale=160:284` → PIL `quantize(colors=14)` для часток кольорів + HSV для медіанної V і середньої S. Потім контакт-аркуші (`montage -tile 7x`; файли передавай аргументами, `@список.txt` заборонений політикою ImageMagick) і дивись очима. **Окремо зніми перші 10 с із кроком 0.5–0.7 с** — там живуть вставки, які рідка вибірка пропускає.

Аудіо ти не чуєш — суди за обвідною RMS по 2 с і за LRA. Вузький LRA (2–3 LU) = рівний голос поверх безперервної підкладки. Кажи чесно, що висновки щодо звуку — із вимірювань.

## Етап 1 — рушій сюжету

1. **Світ зламаний одним фізичним правилом.** Одним. За одну фразу.
2. **Наочний тест** без пояснень (монета дзвенить / тінь відстає / кліпнув).
3. **Правила накопичуються** стеком на екрані і не зникають — зростальна відкрита петля.
4. **Герой порушує правило не з власної волі** — він так влаштований.
5. **Ціну помилки показано на чужому** до того, як ризикує герой.
6. **Фінал — питання.** Титр «ЕПІЗОД 2 · <питання>?»

Теми немає — запропонуй 4–5 варіантів «правило → тест → істота → поворот» і назви найсильніший. Критерій: правило малюється простими формами і керується одним числом.

Істота: одна впізнавана ознака, що пояснює механіку полювання. Обов'язково об'єм: світла грань, темна грань, контровий рим, фонове світіння позаду. Плаский чорний силует на темному читається як палиця.

## Етап 2 — утримання

Ранжування тримається на часі перегляду, частці переглядів до кінця, повторних переглядах і репостах; лайки важать менше. 2+ хвилини роздаються нормально, якщо частка переглядів до кінця тримається.

- **Перші 3 секунди вирішують усе.** Жодних установчих планів. Перший кадр — найсильніша графіка ролика плюс умова («ЯКЩО … — у тебе чотири хвилини»). Найкращий прийом — повноекранна сітка однакових іконок, що гасне рядами, одна лишається.
- **Ритм плавний, не рівний.** Середній план 3.0 с, розкид 2.4–4.2 с. Короткі (2.4–2.8) — ударні біти й лічильники, довгі (3.6–4.2) — ключові образи й кульмінація.
- **Формула за субтитром (0.33 с на слово + 1.2 с, мінімум 2.4 с) — це підлога, а не ціль.** Спершу розстав тривалості за драматургічною роллю плану, потім підніми ті, що нижче підлоги. Не сходиться — ріж фразу.
- **Сусідні плани не повторюють ні тип кадра, ні тип руху, ні головний об'єкт.** Три поспіль на одному графічному об'єкті (глобус, макро-вухо) — завжди помилка.
- **Нова вставка кожні 10–12 с.** Механізм утримання, а не прикраса.
- **Лічильники й числа** дають документальність: «400 разів біля дзеркала», «10 СМ».
- **Звукова діра 2–3 с** у кульмінації, різкий зріз без фейду.
- **Фінал без розв'язки** → повторні перегляди й коментарі.

**Щоб захопити і підлітків, і дорослих** — два шари одночасно. Верхній: щільний ритм, HUD, лічильники, яскраві акценти. Нижній: ясний причинно-наслідковий зв'язок, крупний читабельний текст, людська ставка (брат, донька, сусід). Без ставки швидкий монтаж — порожній кліп.

Обов'язковий набір вставок (мінімум 8):

| Вставка | Роль |
| --- | --- |
| Сітка іконок, що гасне рядами | гак у перші 3 с |
| Глобус/мапа з точками і великим числом | масштаб біди |
| Хвиля по місту, що гасить вікна | момент катастрофи |
| Стек правил ліворуч угорі | зростальна відкрита петля |
| Плашка-попередження в рамці | різкий акцент |
| Чип із пунктирною виноскою до героя | знайомство за 0.5 с |
| Панель піктограм «можна / не можна» | правило без тексту |
| Маска сканування (POV істоти) | зміна точки зору |
| Індикатор рівня / шкала | напруга в числах |
| Екран телефона / чат | впізнаваність |
| Підсумкова картка з галочками | перезавантаження перед фіналом |
| Діагональний спліт двох сцен | зіткнення |
| Поле точок, одна позначена | епілог |

## Етап 3 — рух

Лінійний рух видає аматора миттєво.

```js
const ease=t=>t<0?0:t>1?1:t*t*(3-2*t);
const easeOut=t=>1-Math.pow(1-clamp(t,0,1),3);
const back=t=>{t=clamp(t,0,1);const s=1.70158;return 1+(s+1)*Math.pow(t-1,3)+s*Math.pow(t-1,2);};
const spring=(t,f=3.2,d=5.5)=>1-Math.exp(-d*t)*Math.cos(f*6.283*t);
const anticip=(t,k=0.12)=>t<0.18? -k*Math.sin(t/0.18*Math.PI) : ease((t-0.18)/0.82);
```

- **Антиципація** — різкий рух починається з короткого відводу назад (~5 кадрів).
- **Переліт** — HUD, чипи, плашки з'являються через `back` до 106–110%.
- **Розшарування** — елементи групи приходять зі зсувом 2–4 кадри.
- **Дуги** — предмети, що падають, і руки по `quadraticCurveTo`.
- **Стафаж** — один головний об'єкт руху в кожен момент.

### Вторинний рух — тільки вмотивований

Можна: дихання (тільки верх тіла, `±0.0035*h`), дрейф світіння, дрібне сміття, що летить, рідке підморгування ліхтаря. **Не можна ворушити нерухоме:** вікна не мерехтять, стіни не дихають, асфальт не повзе. Статичний кадр оживляй камерою і героєм.

```js
function lampFlicker(x){                    // ~третина ліхтарів, просідання раз на ~9 с, глибина ≤25%
  const h=Math.abs(Math.sin(x*0.0173)*43758.5453), ph=h-Math.floor(h);
  if(ph>0.34) return 1;
  const cyc=(TNOW*0.11+ph*3)%1; if(cyc>0.05) return 1;
  const u=cyc/0.05; return 1-0.25*Math.sin(u*Math.PI)*(0.55+0.45*Math.sin(u*27));
}
```

Множ лише альфу ліхтаря і його плями світла.

### Фон будується один раз і тільки зсувається

Сид-генератор усередині `draw(p)`, що стартує від поточного прокручування, перезбирає силует щокадру — будинки міняють висоту і вікна, місто кипить. Те саме із зорями, натовпом, полем точок. **Будь-яка випадковість фону обчислюється один раз у кеш** на світ завширшки 3 екрани і малюється зі зсувом за модулем:

### Гігієна полотна — три правила, порушення яких ламає все

1. **Кожен `X.save()` — рівно один `X.restore()` у тій самій функції.** Зайвий restore мовчки знімає стан того, хто викликав: камера `cam()` скидається посеред плану, і все, що намальовано після персонажа (підлога, сусіди, предмети), їде або зникає. Помилка не дає винятку — ловиться лише автотестом (етап 7).
2. **Фон ширший за світ.** Камера панорамує, від'їжджає, центрується не по середині — скраю відкривається порожнеча: «зникає підлога». Будь-яка повнокадрова заливка продовжується за межі:

```js
const rect=(x,y,w,h,c)=>{X.fillStyle=c;
  if(x===0&&y===0&&w===W&&h===H){x=-W*1.5;y=-H*1.5;w=W*4;h=H*4;}
  X.fillRect(x,y,w,h);};
function vgrad(x,y,w,h,c1,c2){
  const g=X.createLinearGradient(0,y,0,y+h); g.addColorStop(0,c1);g.addColorStop(1,c2);
  if(x<=0&&x+w>=W){ x=-W*1.5; w=W*4;
    if(y<=0){X.fillStyle=c1;X.fillRect(x,-H*1.5,w,H*1.5+y+1);}
    if(y+h>=H){X.fillStyle=c2;X.fillRect(x,y+h-1,w,H*1.5);} }
  X.fillStyle=g;X.fillRect(x,y,w,h);
}
```

   Асфальт, бордюр, зебра — теж від `-1.5W` до `2.5W` і вниз до `yG+1.5H`.
3. **Усе, що стоїть на землі, їде зі швидкістю землі (коефіцієнт 1).** Ліхтарі, пляшки, люди на тротуарі. Паралакс <1 лише в дальнього плану (будинки). В асфальту мають бути шви, які їдуть, — інакше під час ходьби підлога стоїть, а ноги ковзають:

```js
function pavement(yG,scroll){ scroll=scroll||0;
  vgrad(0,yG,W,H-yG,P.paveLit,P.pave);
  const st=210, o0=((scroll%st)+st)%st;
  X.save();X.globalAlpha=0.22;
  for(let x=-W*1.5-o0;x<W*2.5;x+=st) rect(x,yG+4,3,H*1.5,'#0E1420');
  X.restore();
  rect(-W*1.5,yG-10,W*4,10,shade(P.paveLit,0.10));          // бордюр
}
```

## Етап 4 — переходи

Жорстка склейка — база (85% стиків). 4–6 змістовних на ролик:

| Перехід | Тривалість | Де |
| --- | --- | --- |

## Етап 6 — графічна база

`lib.js` (компоненти) + `shots.js` (сценарій) у `scene.html` з `<canvas width=1080 height=1920>`.

**Колір.** 12–16 кольорів у `P`, жодного повз. Фон 60–70% кадра. Не більше трьох акцентів у плані, акценти — у типографіці й HUD. Текст до фону ≥4.5:1, обведення обов'язкове.

### Персонаж: два види, а не один

**Головна помилка формату — хода фронтальною фігурою.** Тіло й обличчя анфас, а ноги махають уперед-назад — на екрані це ножиці в боки. Тому `person(x,yFeet,h,o)` має два види:

- `side:0` — **анфас**: стоїть, говорить, жестикулює, крупні плани;
- `side:1 / -1` — **профіль** праворуч/ліворуч: будь-яка хода і біг. Ліворуч — `X.scale(-1,1)` навколо x.

Пропорції від `h`: голова 0.125, плечі 0.112 (напівширина), плече 0.150, передпліччя 0.140, стегно 0.210, гомілка 0.200, таз на `y-0.442h` (стопа рівно на землі з урахуванням підошви).

```js
function _seg(ox,oy,s,a1,a2,l1,l2){          // s — дзеркало по x
  const x1=ox+s*Math.sin(a1)*l1, y1=oy+Math.cos(a1)*l1;
  return [x1,y1, x1+s*Math.sin(a1+a2)*l2, y1+Math.cos(a1+a2)*l2];
}
function _limb(ox,oy,s,a1,a2,l1,l2,wd,col,outline){
  const [x1,y1,x2,y2]=_seg(ox,oy,s,a1,a2,l1,l2);
  if(outline){cap(ox,oy,x1,y1,wd+outline,shade(col,-0.42));cap(x1,y1,x2,y2,wd*0.9+outline,shade(col,-0.42));}
  cap(ox,oy,x1,y1,wd,col); cap(x1,y1,x2,y2,wd*0.9,col); return [x2,y2];
}
function person(x,y,h,o){ o=o||{}; const side=o.side||0; X.save(); let r;
  if(side){ if(side<0){X.translate(x,0);X.scale(-1,1);X.translate(-x,0);} r=_personProfile(x,y,h,o); }
  else r=_personFront(x,y,h,o);
  X.restore(); return r; }              // ОДИН save — ОДИН restore
```

**Анфас.** Порядок: ноги → куртка → шия/шарф → **обидві руки поверх куртки** → кисті → голова. Плечі на `±0.90·shW`. Рукав того самого кольору, що куртка, — тому в руки контур `max(3, h·0.008)` на тон `-0.42` темніший; без нього рука розчиняється в тілі. Рука, намальована до куртки, цілком ховається за нею — «у людей зникають руки». Дихання зсуває лише верх тіла, ноги стоять.

Кути анфас: додатні = **назовні** від тіла (`s=-1` ліва, `s=+1` права), від'ємний лікоть складає передпліччя всередину і вгору.

```js

            rsh:lerp(0.13,0.55,k),rel:lerp(-0.10,-3.30,k),lean:-0.03*k}),             // передпліччя біля обличчя
```

Хапання і вказування рахуй від цілі: довжина руки ≈0.29h, тому кисть має закінчуватися біля руки сусіда, а не пролітати повз нього.

**Профіль.** Порядок: дальня рука (тон −0.26) → дальня нога → ближня нога → корпус у профіль → шия, комір → голова в профіль → **ближня рука поверх корпусу з контуром**. Голова: череп, підборіддя, ніс-трикутник уперед, одне око (білок + райдужка + зіниця + відблиск, зміщені до носа), брова, рот біля підборіддя, вухо в центрі голови, волосся шапкою від лінії чола через маківку до потилиці, коса/пучок — за головою.

**Контакт із землею — автоматичний.** Тіло опускається так, щоб нижня щиколотка стояла рівно на `y`; підстрибування під час кроку виходить саме, окремий `bob` не потрібен:

```js
const ank=(a,k)=>Math.cos(a)*D.thigh+Math.cos(a-k)*D.shin;
const drop=(D.thigh+D.shin)-Math.max(ank(q.lhip,q.lkn),ank(q.rhip,q.rkn));
X.translate(0,drop);
```

У профілі коліно згинається **назад**: гомілка `a1 - kn`. Додатний знак відправить гомілку вперед — пташине коліно.

### Хода без ковзання

Опорна стопа зобов'язана стояти на землі нерухомо. Для цього її x відносно таза змінюється **лінійно** за фазою, а земля їде зі сталою швидкістю, виведеною з геометрії кроку:

```js
function _gaitLeg(p){ const R=0.34; p=((p%TAU)+TAU)%TAU;
  if(p<Math.PI){ const u=p/Math.PI; return {hip:Math.asin(R*(1-2*u)), kn:0.05}; }   // опора
  const u=(p-Math.PI)/Math.PI, e=u*u*(3-2*u);                                       // перенос
  return {hip:Math.asin(-R+2*R*e)+0.26*Math.sin(u*Math.PI),
          kn:0.05+1.00*Math.sin(Math.min(1,u*1.18)*Math.PI)}; }
walk: ph=>{ const r=_gaitLeg(ph), l=_gaitLeg(ph+Math.PI);
  return {rhip:r.hip,rkn:r.kn,lhip:l.hip,lkn:l.kn,
          rsh:-0.40*Math.cos(ph), rel:0.18+0.32*Math.max(0,-Math.cos(ph)),   // руки в протифазі ногам
          lsh: 0.40*Math.cos(ph), lel:0.18+0.32*Math.max(0, Math.cos(ph)), lean:0.045}; },
function gaitSpeed(h,T){ const ax=ph=>{const g=_gaitLeg(ph);
    return Math.sin(g.hip)*h*0.21+Math.sin(g.hip-g.kn)*h*0.20;};
  return (ax(1e-4)-ax(Math.PI-1e-4))/(T/2); }                 // px/с за періоду T
function gaitPhase(t,h,v){ return t/(gaitSpeed(h,1)/v)*TAU; }
```

У плані: `const v=gaitSpeed(h,1.05), sc=v*TIN; street(sc,...); person(x,GY,h,{side:1,pose:POSE.walk(gaitPhase(TIN,h,v))})`. Період кроку ≈1.05 с (≈114 кроків за хвилину). Двоє йдуть поруч — спільна `v`, а фаза в кожного своя від його `h`: у високого крок довший, період більший. Стопа в переносі нахиляється: носок униз під час відриву, вгору перед торканням; в опорі — пласка.

**Волосся анфас** — лінія волосся на `y-0.50·hd`, вище за брови (`y-0.40·hd`). Чубчик, стрічка або шапка, опущені нижче, закривають верх очей — погляд стає сонним. Бічні пасма — ззовні овалу обличчя.

**Субтитри.** Караоке: вимовлені слова білі або акцентні, майбутні `#8A93A0`, у кожного слова обведення (`strokeText`, lineWidth 10, lineJoin round). Блок на 0.645 висоти. Кольори: червоний — загроза, жовтий — числа, зелений — дозволене, фіолетовий — істоти, блакитний — імена.

**Шрифт:** `Inter Display`. Перевір, що є українські літери: `fc-list :lang=uk`. Якщо `і ї є ґ` падають у тофу — візьми `Noto Sans` або `DejaVu Sans`.

**Камера** рухається в кожному плані: `cam(cx,cy,scale,fn)` з `lerp(a,b,ease(p))`. На крупних scale ≤ 1.3.

## Етап 7 — QA до рендеру (обов'язково, цілком)

Кожна помилка нижче вже траплялася і була видна глядачеві. Тести коштують хвилину, рендер — три.

### 7.1 Аркуш поз і аркуш ходи

Окрема `rig.html` (підключає `lib.js` і `shots.js`), сітка 4×2 на повний кадр, під кожною фігурою лінія землі. Аркуш 1: усі пози анфас (`still, idle, sign0/1, grab0/1, flinch0/1`). Аркуш 2: `walk` у профілі, 8 фаз через `TAU/8`. Дивись очима:

- обидві руки видно в кожній позі і вони не тонуть у куртці;
- кисті там, де задумано (біля стегон, біля грудей, біля обличчя, біля сусіда);
- у профілі опорна нога пряма, коліно переносної гнеться назад, руки в протифазі;

### 7.2 Автотести по кожному кадру (`qa.js`, ~2 хвилини)

Один прохід Playwright по всіх кадрах 30 fps, усередині сторінки:

```js
// (а) стек полотна: обгорнути save/restore лічильником і кожну глобальну функцію бібліотеки
let depth=0, under=0; const bad={};
const s0=ctx.save.bind(ctx), r0=ctx.restore.bind(ctx);

for(const k of Object.keys(window)){const f=window[k];
  if(typeof f!=='function'||/^[A-Z]/.test(k)||(''+f).includes('[native code]')) continue;
  window[k]=function(){const d=depth,u=under;const r=f.apply(this,arguments);
    if(depth!==d||under!==u) bad[k]=(bad[k]||0)+1; return r;};}
// ціль: bad = {} і depth=0 наприкінці кожного кадру

// (б) стрибки всередині плану: кадр до кадру на 108×192, середня |різниця| по RGB.

// (в) діри у фоні: QA_CLEAR='#FF00FF', у QA_HOOK порахувати частку пурпурових пікселів

```

Плюс колишні: сусідні плани різняться (середня |різниця| 72×128 > 18), субтитр ≤ 0.86 ширини, фон стабільний (4 кадри поспіль, верхні 72%: без прокручування <0.5, із прокручуванням <2.0).

### 7.3 Контакт-аркуші очима

## Економія токенів

- Риг, пози, хода, гігієна полотна, згладжування, цілі грейду і звуку вже тут — не виводь наново.
- QA-скрипт пиши один раз і перевикористовуй у кожному ролику; він дешевший за будь-який перегляд очима.
- Проби одним прогоном, дивись контакт-аркушами, повний розмір лише для ризикованих кадрів.
- Правки пачкою. Бібліотеку пиши один раз цілком, далі точкові заміни.
- Продовження серії: копіюй `lib.js`, `rig.html`, `qa.js` з попереднього ролика, міняй істоту, палітру і `shots.js`.
