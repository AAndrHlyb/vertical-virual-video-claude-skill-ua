# Зацикленные простые ролики

Движок и набор элементов готовы. **Пиши только `film.js` на 20–60 строк.** Код `kit.js` не читай — ниже вся шпаргалка.

## Старт

cd ~/vsf/loop-shorts && mkdir -p projects/<slug> && cp scene.html projects/<slug>/

## film.js
```js
import * as K from '../../kit.js';
const { C, T, M, seg, ph } = K;
K.film({ d: 10, bloom: 0, sfx: [[0.2, 'draw'], [3, 'snap'], [5, 'ding']], draw(t) {
  // всё — функции от t (0..d). В t = d кадр обязан совпасть с t = 0.
} });
```
`film({ d, draw, sfx, bloom=0, zoom=0.86, xfade=0, drift=0.02, vignette=0, grain=0, title, narr })`. Холст 1080×1920, фон чёрный. `xfade` — последние N секунд плавно перетекают в первый кадр (файл начинается чисто, без кадров из конца; длина петли = d). Финал держи хотя бы xfade секунд до конца. `drift` — медленное «плавание» камеры, чтобы паузы не выглядели зависанием (0 — выключить).
**Безопасная зона:** `zoom: 0.86` (по умолчанию) — «камера» чуть отдалена и сдвинута влево-вверх, чтобы картинка не залезала под лайки/аватар справа и подпись снизу. Рисуй как обычно в координатах 1080×1920, держи главное в x 80–1000, y 250–1700. `zoom: 1` — только для фона во весь кадр.

## Петля — правила
- Повторяющееся движение — только через `ph(t, n)` / `osc(t, n)` с **целым** n: тогда шва нет.
- Сюжет «туда-обратно»: `k = seg(t, 1, 2.4) * (1 - seg(t, 8, 9.2))` — к концу всё вернулось в начальное состояние.
- Ключи `tl(t, [[0,v0],[2,v1],…,[d,v0]])` — последний ключ равен первому.
- Не замыкается само (итоговая формула, счётчик, текст) — **`xfade: 1–1.5`**: финал плавно перетекает в начало. **Никогда не гаси всё в чёрный** — в петле это выглядит как сбой.
- После рендера `loopcheck.py` обязан сказать «ОК».

## Частые ошибки (их ловит loopcheck)
- **Пропадает картинка** — изинги с перелётом `eBack`/`back`/`spring` бывают > 1 и < 0 уже в середине анимации. Только для положения/размера, **никогда в условиях** `if (go < 1)`: условия — по времени `t`.
- **Чёрный экран** — затемнение в конце; заменить на `xfade`. Тёмный провал на стыке бывает и при `xfade`, если первый кадр пустой: **главная фигура стоит с t = 0** (без «рисования на глазах» с нуля), меняются только подписи и формулы.
- **Фриз** — кадр стоит > 0.6 с. В паузе между шагами что-то живёт: пульс подсветки `bump`, живое число, `breathe`, `ripple`; `drift` включён по умолчанию.
- **Рывок** — элемент появился/исчез скачком: появление через `seg(...)` как прозрачность, не через `if`.
- В однострочнике не ставь `// комментарий` посередине — он отрежет остаток строки.
- `draw` не падает молча: ошибка печатается рендером как «ОШИБКИ страницы» — читай вывод.

## Хук и удержание — первые 3 секунды решают
- **0–0,8 с — удар:** резкое движение + звук (`boom`/`whoosh`): взрыв частиц из центра, фигура влетает с `eBack`, быстрый зум. Первый кадр уже яркий и цветной, не пустой контур.
- **«А если сломать?»** — поменяй ключевой параметр и покажи, как всё разваливается (красный, `icon('cross')`), потом верни правильный (зелёный, `check`). Контраст держит внимание лучше объяснений.
- **Событие каждые 1,5–3 с** и постоянное движение: вращение `ph(t, n)`, живые числа, частицы, волна подсветки `bump(t, t0 + i * 0.1, …)` по элементам. Медленно — только финальное раскрытие (3–4 с).
- **Много элементов = красиво:** сотни точек/кусков с общим правилом (подсолнух, спираль, сетка) и перекраска по правилу `hue(i % n / n)` — проявляет скрытую структуру.
- **Смена узора без мерцания:** не крути параметр через все промежуточные значения (точки на миг слипаются — вспышки), а двигай каждую точку из старого положения в новое: `lerp(pos(A0), pos(A1), k)`.

## Понятность — важнее красоты
Красивый ролик, в котором ничего не понятно, — провал. Зритель без знаний должен понять, **что происходит и почему**.
- **Сначала правило крупно и медленно** — на 1–6 элементах, камера близко; потом ускорение до сотен и отъезд. Видно, откуда берётся узор.
- **Каждый этап — одна строка сверху** (4–8 слов, крупно): что сейчас видим и почему («120° — 3 луча, между ними пустота»). Это подпись к картинке, не субтитры. В стиле «Без слов» — тоже, если без неё неясно.
- **Одна новая мысль за раз:** сначала выдели одну вещь (одну спираль, один кусок), потом покажи все.
- **Сравнение объясняет «почему»:** у неправильного варианта подпиши, чем он плох; у правильного — чем хорош.
- **Каждое число объяснено:** откуда взялось (`137,5° = 360°/φ²`) и что значит (`φ — золотое сечение`).
- **Проверка по листу кадров:** для каждого кадра скажи одной фразой «что тут происходит». Не получается — добавь подпись или упрости.
- Цвета и подсветка меняются плавно (наложение с прозрачностью `circ(…, { fill, fa })`), не переключением по порогу — иначе рывок.

## Живые движения — обязательно
- Ходьба — только `gait` (ноги на земле), не `POSE.walk` на месте под скользящим миром.
- Стоящий человечек — `breathe(pose, t)`, не замороженная поза.
- Предметы прибывают с `eOut`/`back`/`eBack` (замах и перелёт), а не линейно; переходы поз — `mixPose(A, B, seg(...))`.
- Причина и следствие в одном кадре: толкнул — сразу поехало; стыковка — `snap` в тот же момент.

## Подробность — по умолчанию для теорем и формул
Зритель должен понять доказательство **без знаний заранее**, а не просто увидеть красивую анимацию.
- **5–8 шагов, 20–40 с.** Каждый шаг: подпись `caption(n, …)` одной мыслью + своё действие на экране + звук. Шаг длится 3–5 с, следующий начинается, когда предыдущий понят.
- **Сначала исходные данные:** что дано (фигура, обозначения r, a, b), какие известные факты используем (например, длина окружности 2πr), и только потом — хитрость.
- **Каждая величина подписана в момент появления:** стороны, радиусы, углы — `sideLabel`, `brace`, `angleArc`; цвет подписи = цвет части фигуры.
- **Покажи, почему это работает,** а не только результат: предельный переход (8 → 16 → 32 сектора), «эта часть равна той» (подсветка `C.yel` обеих), что не меняется (живое число).
- **Вывод формулы по шагам** через `exChain`: от определения к ответу, 2–4 перехода (`S = frac{2πr}{2} · r` → `S = πr · r` → `S = πr^2`), итог в рамке `exBox(E,'ALL')` + `ding`.
- **Последний шаг — итог словами** `caption(0, 'Площадь круга = πr²', …, {tc: C.yel})`, затем `xfade` перетекает в первый шаг.
- Без подписей — только если пользователь прямо просит «без слов, как в референсе» → стиль «Без слов» ниже.

## Шпаргалка kit.js
**Время:** `ph(t,n)` фаза 0..1 · `osc(t,n,amp)` · `seg(t,t0,t1,e?)` · `bump(t,t0,dur)` 0→1→0 · `fadeIO(t,f)` · `tl(t,keys)` · `step(t,[0,3,6])→[i,k]` · изинги `eIO eOut eIn back spring`, `lerp clamp inv`.
**Цвета `C`:** ink dim faint · pink blue indigo yel (как в референсе-доказательстве) · green red orange gold violet teal fire. `hue(h, s, l, a)` — цвет по кругу h = 0..1 (раскраска множества точек).
**Стиль линии `o`:** `{ c, w, fill, fa, a, glow, dash:[14,10] }`; последний аргумент `k` — «рисование на глазах» 0..1.
**Примитивы:** `line(a,b,o,k)` `path(pts,o,k)` `poly(pts,o,k)` `circ(x,y,r,o,k,a0)` `dot(x,y,r,c,glow)` `box(x,y,w,h,o,k)` `rbox(x,y,w,h,r,o)` `arrow(a,b,o,k)` `sector(x,y,r,a0,a1,o)` `curve(f,x0,x1,map,o,k)` `axes(cx,cy,w,h,ux,uy)→map` `grid` `wave(x0,x1,y,amp,n,t,o)` `ground(y,o)` пол, гаснущий к краям.
**Геометрия:** `mv rot scl ctr lerpP(A,B,k)` морф · `rigid(pts,dx,dy,ang,k)` · `mid dist ang(P,Q)` · `regular(cx,cy,r,n)` · `rectP` · `rtri(R,a,b,th)` прямоуг. треугольник · `rightMark(R,A,B)` `angleArc(P,A,B,r,o,k)` `tick(a,b,n)` `sideLabel(s,a,b,inside)`.
**Текст:** `T` заголовки (Oswald) · `M` математика курсивом · `S` текст с засечками · `mono` · `type(s,x,y,t,t0,cps)` печатная машинка · `formula([['c²',t0,цвет],[' = ',t1],…],x,y,t,{size,a})` растёт по частям · `pow_('1,01','365',' ≈ 37,8',x,y,o)` любая степень · `frameBox(x,y,w,h,k)` рамка итога · `wrapLines(s,maxW,size)`. Опции текста: `{ size, color, alpha, weight, align }`.
**Индикаторы:** `bar(x,y,w,level,c,label)` светящаяся полоска · `levelColor(v)` · `ring(x,y,r,k,c)` · `counter(v,x,y,{pre,post,size})` · `bars(x,y,w,h,vals,k,cols,labels)` · `checkbox(x,y,s,k)` · `chain(x,y,n,done)` серия дней.
**Эффекты (петлевые):** `flame(x,y,s,t,k,seed)` огонь, k 0..1 (0 — угли) · `embers` · `halo(x,y,r,c,a)` · `burst(x,y,t,t0,dur,n,c)` искры · `ripple(x,y,t,n,R)` · `dust(t,n)` · `drops(x0,y0,x1,y1,t,n,c)` струя · `spotlight(x,y,r,a)`.
**Формулы как в Manim** (корни, степени, дроби, превращения):
- синтаксис: `'√{50} + √8'`, `'5√2'`, `'x^2'`, `'√{5^{2@s} × 2}'`, `'frac{a+b}{2}'`, `'(5 + 2)√2'`; буквы курсивом, цифры прямо.
- ключи: каждый знак — «текст#номер»; при превращении одинаковые ключи **переезжают**, остальные растворяются/появляются. Свой ключ `50@a` → в следующем шаге `25@a` заменится на том же месте и поедет вместе с ключом.
- `ex(src,x,y,{size})` → раскладка · `drawEx(E,{write,a,color,colors})` (`write` 0..1 — «пишется») · `morphEx(srcA,srcB,k,x,y,o)` · `exChain(steps,marks,dur,t,x,y,o)` → текущая раскладка (цепочка шагов одной строкой) · `exBox(E,keys,c,k)` рамка (ключ, массив, текст или `'ALL'`) · `exStrike(E,keys,c,k)` красный крест · `exBounds(E,keys)`.
- образец: `examples/algebra` (√50 + √8 → неверный путь √58 зачёркнут → 7√2).
**Человечек:** `fig(x, groundY, h, pose, {dir:±1, c, glow, a})` → `{hand, hand2, head, hip, top}` (точки для реквизита). Ноги сами встают на `groundY`.
Позы `POSE.`: `stand walk(p) run(p) sit pour(k) lift(k) think cheer(lt) slump push(p) phone read climb(p) sleep wave(lt) bow(k)`; `p` = `ph(t,n)`. Смесь: `mixPose(A,B,k)`. Своя поза: `{lean, nod, sh:[a,b], el, hip, kn, up}` — углы от вертикали, 0 вниз, π/2 вперёд, π вверх.
**Живая ходьба (всегда для ходьбы по полу, лестнице, горке):** `const g = gait(u, L, ground, h, {map, lean})` — u путь бёдер, L шаг, `ground(x)` → y пола в мире, `map(x,y)` мир→экран (камера). Рисуй `fig(0, 0, h, g.pose, { feet: g.feet, hip: g.hip })`: ступни стоят и не скользят, колени гнутся сами, задняя нога встаёт на носок. Петля: за ролик чётное число шагов, мир сдвигается ровно на период. Лестница: `ground = x => -Math.floor(x / sw) * sh`, `L = sw`, h ≈ 2.3·sw. Щелчок шага — при целом `u/L`. Образец: `examples/versus`.
**Реквизит `prop.`:** `can(x,y,s,a)→носик` лейка · `cup book phone dumbbell rock plant(x,y,s,k) seed candle(x,y,s,t,k) clock(x,y,r,t) hourglass(x,y,s,k) stairs(x,y,n,sw,sh)→ступень(i) mountain→вершина flag(x,y,s,t) trophy coin bulb(x,y,s,on)`.
**Значки:** `icon(имя,x,y,s,{c,fill,glow,k})`: check cross heart star bolt target lock sun moon plus minus eq arrowR loop.
**Подробное доказательство:** `caption(n, текст, t, t0, t1, {tc, size})` подпись шага внизу с номером в кружке (n = 0 — без номера, для итога) · `brace(a, b, подпись, {c, lc}, k, side)` фигурная скобка размера (side = 1 — наружу сверху/справа) · `stepAt(t, [[t0,t1],…])` → номер текущего шага.

## Звук — без музыки
`sfx: [[время, вид, громкость?, длительность?]]`. Хвосты у конца петли сами переходят в начало.
рисование → `draw` · сдвиг/переезд → `slide` · стыковка → `snap` · появление → `pop` · итог → `ding` · шаг → `click` · огонь → `crackle` · вода → `drip` · тяжёлое → `thud` · рост → `rise` · смена → `whoosh` · пульс → `heartbeat`.

## Цикл работы (цель — ≤10 тыс. токенов на ролик)
1. Идея в 2–3 строки: что в петле, что повторяется, где «удар». Не спрашивай пользователя, если просьба ясна.
2. `film.js`.
3. `node ../vertical-story-film-ua/engine/render.mjs projects/<slug> --stills 0.5,4,8` — один лист, поправить, не больше двух раз.
4. Рендер: `node ../vertical-story-film-ua/engine/render.mjs projects/<slug>` (без свечения ≈ 0.1 с/кадр; `glow`/`bloom` ≈ 0.5 с/кадр).
5. `python3 ../vertical-story-film-ua/engine/audio.py projects/<slug>` → `out/final.mp4`.
6. `python3 loopcheck.py projects/<slug>/out/final.mp4` — шов, чёрные кадры, пропадания, фризы, рывки. Пока не «ОК» — не отдавать.
7. Отдать `final.mp4` (лёгкая копия: `ffmpeg -i final.mp4 -c:v libx264 -preset veryfast -crf 23 -c:a aac -b:a 160k out.mp4`).
Если в ролике есть голосовой текст: `narr` + `python3 ../vertical-story-film-ua/engine/subs.py projects/<slug>` → `.srt` отдельным файлом. Без текста субтитров нет.

## Стили
- **Доказательство** (как 3Blue1Brown): `bloom: 0`, линии `w: 3`, заливки pink/blue/indigo/yel, формулы `M`/`formula`, движущаяся часть подсвечивается `C.yel`. 20–40 с, 5–8 шагов с подписями (см. «Подробность»). Образец: `examples/circle` (площадь круга, 7 шагов).
- **Без слов** (как Manim-референсы): никаких `caption`, текст — только формула сверху и её превращения `exChain`. Смысл несут фигуры: подписи величин на самой фигуре (`brace`, `M`), квадраты/части, растущие с `eBack`, подсветка части фигуры и члена формулы **одновременно** (`bump` + `exBox`), частный случай в конце (угол → 90°, D → 0), который превращает формулу в знакомую. Образцы: `examples/cosines` (теорема косинусов), `examples/golden2` (золотой угол: правило крупно → лавина семечек, «а если сломать» с подписями, одна спираль → все 21 и 34).
- **Мотивация:** `bloom: 0.3`, белые `fig` с `glow`, `ground`, огонь, полоски green/red, заголовок `T` крупно. 6–15 с.

Примеры (читать, только если нужен образец): `examples/proof` — углы треугольника, `examples/versus` — «1% каждый день» (живая ходьба по лестнице), `examples/algebra` — превращения формул, `examples/kit` — все элементы на одном кадре.
