# vertical-virual-video-claude-skill-ua

Скіл для Claude, який робить вертикальні сюжетні ролики — 9:16, під TikTok, Reels і Shorts.

Відео не генерується нейромережею, а **рендериться кодом**: 3D-сцени й персонажі на three.js, 2D-інфографіка поверх, монтаж із переходами, процедурна партитура й шуми. Персонаж не мутує між кадрами, склейки стають рівно по кадру, а правка коштує секунди замість повного перегенерування.

## Що всередині

`vertical-story-film-ua/` — сам скіл:

| Шлях | Що це |
| --- | --- |
| `SKILL.md` | інструкція для Claude: жанри й скелети сюжетів, каталог хуків, правила монтажу, світло, кадр 9:16, звук, робочий цикл, часті помилки |
| `engine/core.js` | цикл кадру, плани, переходи (`cut match whip push pull dim flash glitch`), авто-камера, світіння, віньєтка, зерно, плашка з годинником, текст |
| `engine/stage3d.js` | схеми світла (`noir office lab alarm night warm`), прожектор з конусом, кімнати, вікно на нічне місто, текстури, живі екрани, реквізит |
| `engine/cast3d.js` | 3D-люди: 10 зачісок, 6 типів одягу, капелюхи, окуляри, міміка, пози, хода з автоматичним контактом стопи |
| `engine/render.mjs` | паралельний рендер у headless Chromium → ffmpeg; аркуші кадрів, чорновий режим |
| `engine/audio.py` | партитура за настроєм, 20 видів шумів, пригинання під голос, −14 LUFS, перевірка «чи чути на телефоні» |
| `engine/subs.py` | `.srt` і текст озвучки з таймінгом; підгонка планів під записаний голос |
| `engine/qa.py` | жвавість кадру, мертві шматки, чорні кадри, звук, порівняння з еталоном |
| `example/` | робочий приклад усіх прийомів (≈12 с) |

## Чому рушій, а не код з нуля щоразу

Раніше Claude щоразу писав рендер, риг і звук заново — і щоразу ловив ті самі баги: зникала підлога, ховалися руки, профіль голови малювався криво, зачіска з'їжджала, звук був лише в басах і на телефоні його не було чути. Тепер усе це — один перевірений рушій:

- **Профіль голови й зачіски** більше не малюються окремо: персонаж — 3D-об'єкт, і камера знімає його з будь-якого боку.
- **Лікоть і коліно** гнуться лише в правильний бік за побудовою.
- **Звук** будується з енергією в 300–4000 Гц і перевіряється автоматично.
- **Claude пише лише `film.js`** — сценарій, світи, плани, звук. Це в рази менше токенів на ролик.

## Встановлення

Поклади теку `vertical-story-film-ua/` у свої скіли Claude. Потрібні Node.js + Playwright з Chromium, `ffmpeg`/`ffprobe`, Python з `numpy` і `scipy`, ImageMagick. Шрифти з кирилицею й three.js уже в репозиторії.

```bash
cd vertical-story-film-ua
cp -r example projects/my-film                       # редагуєш лише film.js
node engine/render.mjs projects/my-film --sheet 1.5 --draft
node engine/render.mjs projects/my-film
python3 engine/audio.py projects/my-film && python3 engine/subs.py projects/my-film
```
